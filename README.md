# 🎵 TikTok Mobile App Clone (Expo React Native)

[![React Native](https://img.shields.io/badge/React_Native-0.74+-61DAFB?style=for-the-badge&logo=react&logoColor=black)](https://react.dev/)
[![Expo](https://img.shields.io/badge/Expo-51+-000000?style=for-the-badge&logo=expo&logoColor=white)](https://expo.dev/)

Ứng dụng di động mạng xã hội video ngắn **TikTok Clone** với thao tác vuốt lướt video dọc mượt mà.

```bash
git clone https://github.com/nguyenhuynhdt37/tiktok-clone-react-native.git
cd tiktok-clone-react-native
npm install
npx expo start
```
