---

## ✨ Tính Năng Nổi Bật

- 🎬 **Vertical Video Feed:** Lướt xem video dọc với thao tác swipe mượt mà.
- ❤️ **Tương Tác Video:** Thả tim, bình luận, chia sẻ video.
- 👤 **Trang Cá Nhân:** Hiển thị danh sách video đã đăng, lượt follower.

```bash
git clone https://github.com/nguyenhuynhdt37/tiktok-clone-react-native.git
cd tiktok-clone-react-native
npm install
npx expo start
```
